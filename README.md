# Shivam Saini — Portfolio

A static portfolio built with HTML, CSS, and vanilla JavaScript. It keeps the charcoal + muted-green visual direction while following a familiar portfolio structure:

- Home
- About
- Skills, grouped by languages, frontend, backend, databases, tools, and core strengths
- Projects
- Open source
- Contact

## Preview locally (Windows)

1. Extract this ZIP.
2. Open the **portfolio-redesign** folder in VS Code.
3. In VS Code, choose **Terminal → New Terminal**.
4. Run the command below from inside `portfolio-redesign`:

   ```powershell
   python -m http.server 5500
   ```

5. Open <http://localhost:5500> in your browser. Keep the terminal running.

If Python is unavailable, open `index.html` directly, but using the local server is recommended.

## Links

The navigation links scroll to sections on this page. GitHub, project demos, pull requests, LinkedIn, and email links use the destinations included in `index.html`. External links open in a new tab.

If a project demo itself is unavailable, that is a separate issue from the portfolio link; the destination site must be published for its demo to load.

## Publish with GitHub Pages

1. Review the page locally first.
2. Copy the contents of this folder into the **root** of your existing `portfolio` repository. Keep your existing `.git` folder and any assets you still need.
3. Commit and push the changes to GitHub.
4. In the repository, open **Settings → Pages** and ensure GitHub Pages is configured for the intended branch and root folder.
5. Wait for the deployment to finish, then open your portfolio URL.

This ZIP does not change your GitHub repository or live website automatically.
