## 💻 Run Locally

This portfolio is a static website built with HTML, CSS, and JavaScript.

1. Clone the repository:

   ```bash
   git clone https://github.com/shivam-saini18/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
